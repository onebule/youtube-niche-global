# 0.7.0

- 新增选题仓库、角色库、技能库，支持本机编辑、搜索、状态筛选和 JSON 合并导入导出。
- 选题可创建制作任务，角色与技能可复用到 AI 文案和分镜提示词。不会自动提交付费生成。

# v0.5

- Windows 与 Mac 启动脚本自动获取并校验官方 Node.js 22 运行环境，Mac 自动识别芯片架构。
- 新增独立启动器：重复启动复用、旧版冲突提示、备用端口与启动日志。
- 支持 tools 子目录放置本地视频工具。
- 新增官方校验清单/下载失败的模拟安装测试与启动器测试。

未在 Windows/macOS 真机验证；首次官方在线下载、真实账号生成及浏览器视觉验证仍待完成。此版为解压启动包，不是签名 EXE/DMG 或完全离线包。

# v0.4

- 新增本机环境检查与制作流程指引页面。
- 完整导出/恢复生成历史、队列及草稿；不保存会话凭证。
- 本地磁盘备份列表、保存、下载、恢复与删除；拒绝任意文件路径。
- 修复备份对象引用当前编辑数据的问题，恢复失败时回滚已写入字段。
- 备份读取当前最新文档，减少跨页面旧数据覆盖。

验证：新增备份导出/恢复、写入失败回滚、磁盘读写、敏感字段拒绝、路径与跨站边界测试。真实浏览器及原站付费生成仍未验证。
