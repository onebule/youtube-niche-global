# 0.12.0

- 新增 Windows / Mac 本机系统文字配音，可选系统声音与语速；不调用云端配音服务。
- 支持读取已保存正文或分镜文案，试听、下载 WAV，并将生成音轨用于当前视频导出。
- 配音纳入取消、临时文件清理和更新前任务检查；文本通过本机文件或标准输入传递，不拼接到命令中执行。
- 可用语言和声音依赖系统语音包；未包含声音克隆、自动字幕识别或 YouTube 自动发布。

# 0.11.0

- 新增原站 Google 登录：在系统浏览器选择账号，授权后自动连接桌面工作台，无需输入 Gmail 密码。
- 使用 PKCE、随机本机回调端口、一次性状态校验；授权码交换后再向原站验证用户身份。
- 支持取消、超时和返回应用后接收登录结果；访问令牌不放入浏览器 URL 或备份文件。
- 保留原站邮箱密码入口，修正登录方式提示。
- 已验证原站允许随机本机回调；真实 Google 账号最终授权仍需用户在浏览器完成。

# 0.10.1

- 修复桌面 API 请求未使用 Electron 系统网络通道的问题，让登录、模型与查询请求遵循系统网络/代理配置。
- 新增不提交账号密码的认证连接检测，区分服务不可达、服务异常与账号验证失败。
- 登录请求增加超时和明确错误提示，保持生成请求不自动重试。
- 仍只支持原站邮箱密码登录；Google 跨站授权尚未实现。

# 0.10.0

- 本地成片导出新增横屏 720p/1080p、竖屏 1080p 和方形 1080p，按比例缩放并补黑边。
- 可导入已有配音音轨，设置配音与原片音量；短音轨补静音、长音轨截到视频结束。
- 导入和编辑 SRT 字幕，校验时间轴与视频时长；导出 MP4 可切换字幕轨道和独立 SRT。
- 新增导出视频预览、字节范围读取与取消处理；修复原音轨过短导致视频截断的问题。
- 未包含自动语音识别、自动配音、字幕烧录或 YouTube 自动发布。

# 0.9.0

- 新增软件在线更新页和原生菜单，启动时检查正式 Release；手动下载、取消和显示进度。
- 固定更新来源、校验系统架构与版本、SHA-256 双重检查，拒绝损坏、截断或降级安装包。
- Windows 在保存磁盘备份、确认后退出并启动 NSIS 更新；Mac 未签名，支持下载并打开 DMG 后手动覆盖安装。
- 更新前检查本地合并与上传、生成队列；更新失败保留当前应用和数据。
- 正式安装包与更新清单发布到公开 GitHub Release，长期链接无需登录。

# 0.8.0

- 新增热点雷达：复用原站只读 YouTube 公开数据接口，支持关键词、市场、发布时间、长短视频筛选。
- 新增对标频道收藏和当前样本比较，不将搜索样本描述为频道完整统计。
- 支持热点视频保存到选题仓库；重复保存不创建重复条目。
- 研究结果与收藏纳入完整和磁盘备份；保留缺失值，严格校验增长快照与链接。
- 累计播放、发布以来日均、两次采集增量分别展示；查询时间和数据采集时间分别标注。

# 0.7.0

- 新增选题仓库、角色库、技能库，支持本机编辑、搜索、状态筛选和 JSON 合并导入导出。
- 选题可创建制作任务，角色与技能可复用到 AI 文案和分镜提示词。不会自动提交付费生成。
- 资源库纳入完整备份和磁盘恢复；冲突条目禁止静默覆盖。
