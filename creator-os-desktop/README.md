# Creator OS 独立工作台 · 本地安装版 v0.5

## Windows 与 Mac 启动

无需先手动安装 Node.js。完整解压后运行：

- Windows：双击 `Start-Windows.cmd`。
- Mac（Apple 芯片或 Intel）：双击 `Start-macOS.command`。
- Linux：运行 `sh Start-Linux.sh`。

启动器优先使用包内/已有 Node.js 22+；没有时首次联网从 nodejs.org 获取当前 Node.js 22 对应平台版本，核对官方 SHA-256 清单后安装到当前文件夹的 runtime 子目录。它不安装全局 Node.js，也不需要 npm install。

启动后自动打开本机浏览器。重复启动同一版本会打开已有服务；端口被其他程序占用时可选择后续端口并记住地址。浏览器存储按地址区分，端口变化时原数据仍在原地址。

保留启动窗口，按 Ctrl+C 停止服务。旧版仍在运行时，须先关闭旧版再启动新版。启动日志位于 `data/startup.log`。

首次准备环境和 AI 服务需联网；此包不是包含所有运行环境的完全离线安装器，也不是已签名的 EXE/DMG。Mac 启动脚本如被系统要求确认，请按系统允许的打开流程处理；不要关闭系统安全功能。

开发环境也可使用 `npm start` 或 `node launcher.mjs --check`。

## v0.5 安装与启动优化
- Windows / Mac 自动准备官方 Node.js 22 运行环境，核对 SHA-256 后解压；Mac 自动识别 Apple/Intel。
- 启动路径支持空格；下载失败与校验失败会停止执行并清理暂存文件。
- 重复启动复用同版本服务；旧版本运行时提示先停止。
- 端口冲突时选择备用端口，并提示浏览器存储地址差异。
- 可把 FFmpeg 和 ffprobe 可执行文件放入 `tools/`，无需修改全局 PATH。

## v0.4 本地使用与备份
- 新增“使用与备份”页：检查 Node.js、FFmpeg/ffprobe 和浏览器存储可写性，提供完整操作顺序入口。
- 备份扩展为任务、分镜、发布素材、统计、文案/参数草稿、按账号保存的生成历史和队列。登录凭证及媒体二进制不进入备份。
- 可把备份保存到工作台文件夹 `data/backups`，支持列表、下载、恢复和删除。升级、换文件夹或迁移电脑时，请保留/复制此目录。
- 恢复队列不会自动提交；提交中条目标记为待确认。写入失败时尝试回滚之前的数据；空间不足时仍应保留原备份文件。
- 恢复前请暂停并关闭其他生成/编辑标签页，避免旧页面覆盖已恢复数据。

## v0.3 优化
- 修复提交时分辨率被选项重建覆盖的问题；图片画幅/分辨率读取模型声明。
- 按原站契约校验视频时长、提示词长度与分辨率，包括 MiniMax 的 768P/2K、Veo 的 8 秒要求。
- 自动保存发布素材、生成参数、提示词与 AI 文稿结果；返回工作台保留上次打开的页面。
- 生成记录增加类型、状态、提示词搜索与分镜定位；同一状态不重复重建预览，减少播放被刷新打断。
- 修复清空分镜后刷新重现示例的问题，编辑分镜时保留其他页面回填的生成结果。
- 远端生成失败后暂停批量队列；暂停时及时释放标签页队列锁，存储失败时停止提交。
- 本地视频合并显示数量/大小汇总，可手动清理临时素材与输出。

## 已有功能
- 任务：新建、编辑、删除、截止时间、阶段与完成状态，本机保存。
- 分镜：编辑、删除、追加 JSON 导入、JSON 导出、持久保存、选择分镜送往生成中心。
- 图片/视频批量队列：模型与参数快照、逐条提交、暂停、恢复、失败后手动重试、结果回填分镜；按登录账号保存生成历史和队列。
- 队列遇到不明提交结果暂停，不自动重试；需核对原站任务后关联。使用 Web Locks 防止多个标签页同时启动队列。
- AI 发布素材：沿用原站文本模型，生成标题、简介、置顶评论、社区贴文、封面提示词与分镜；预览后手动应用。
- 数据：导入每日视频 CSV；总览和周报依据导入记录计算播放量、订阅、收入、加权点击率。缺失字段不伪造为 0；缺少历史日期时不显示可靠环比。
- 备份：导出/恢复任务、分镜、发布素材、统计记录与分镜结果元数据。登录凭证不进入备份；生成中心历史与队列已纳入备份。
- 本地视频合并：选择本机视频，调整顺序，FFmpeg 处理后下载 MP4。输出统一 1280×720 / 30fps，保留音轨，无音轨补静音。视频只传至本机服务，不传云端。

## 推荐流程
1. 启动工作台，进入资产生成页粘贴文案。
2. 点击 AI 生成素材，登录原站邮箱密码，检查文本模型，生成并预览。
3. 应用发布素材与追加分镜，回到视频制作页检查提示词。
4. 勾选分镜，批量生图；生成中心选择可用图片模型，加入队列并启动。
5. 图片完成后，回到分镜页选择批量视频。图生视频沿用对应分镜在当前账号下生成的首帧资产。
6. 下载生成结果，在视频合并页选择本机片段、排序、合并与下载。
7. 数据管理页下载 CSV 模板，填入每日实际数据后导入、查看周报、备份。

## 使用边界
- AI 及账号接口已按原站客户端契约实现，测试使用模拟上游，没有已登录账号的真实付费生成验证。
- 当前没有浏览器工具，未验证真实浏览器视觉、文件上传、跨平台启动及 Google OAuth。安装脚本通过本地模拟下载测试；尚未在 Windows/macOS 真机及官方在线下载环境验证。
- 仅 Google 登录且未设置密码的账号仍需配置 OAuth 回调；此版支持原站邮箱密码登录。
- 队列在生成中心页面打开时运行，刷新后暂停，需手动继续；关闭页面不会撤销原站已提交任务。
- 任务、分镜和统计是本机工作空间；生成历史与队列按原站 userId 区分。建议同一时间仅使用一个标签页编辑。
- 统计数据来自手动 CSV；没有自动 YouTube Analytics 同步、发布到 YouTube、收入抓取或完整异常诊断系统。
- 没有多人云同步、自动配音、字幕、转场或自动剪辑。
- 合并功能需要用户另行准备 FFmpeg 与 ffprobe，放到 tools 子目录或加入 PATH；未打包这些二进制。每段最多 200MB，一次最多 30 段。
- 本地服务默认仅监听 127.0.0.1；工作台与原网站分别保存，不改动原站部署及数据库。

## 验证
`npm test` 覆盖固定 API 代理、授权与幂等头、队列中断/顺序/重试、CSV 校验与统计、模拟 DOM 页面渲染、AI 草稿应用，以及真实 FFmpeg 两段视频合并（含有音频和无音频的输入）。无 FFmpeg 时合并测试会明确跳过。
