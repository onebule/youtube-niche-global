Creator OS 本地安装版 v0.5 · Windows / Mac

【启动】
1. 将压缩包完整解压到你有读写权限的文件夹。不要直接在压缩包里运行。
2. Windows 双击 Start-Windows.cmd；Mac 双击 Start-macOS.command。
3. 无需预先安装 Node.js：如果电脑没有可用版本，首次启动会联网下载官方 Node.js 22，校验后存入 runtime 子目录。
4. 启动完成后自动打开浏览器，通常为 http://127.0.0.1:4173 。以启动窗口显示的地址为准。
5. 运行时保留启动窗口；停止时按 Ctrl+C。关闭浏览器不会停止服务。

【Mac】
同时支持 Apple 芯片与 Intel，脚本自动识别。不包含已签名的 .app/.dmg。若系统提示确认启动脚本，请使用系统允许的打开方式，不必关闭系统安全功能。
如果解压工具没有保留执行权限，可在终端进入解压文件夹运行：
sh Start-macOS.command

【Windows】
需要 64 位 Windows 10 或更新版本，以及系统自带 Windows PowerShell。脚本仅为当前启动进程指定脚本执行选项，不修改全局执行策略。不需要管理员安装 Node.js。

【首次下载失败】
检查能否访问 https://nodejs.org/，并确认解压目录可写，再重新运行。
也可以自行安装 Node.js 22+ 后重新运行脚本。
校验失败时不会执行下载文件。

【升级与数据】
升级前在旧版保存备份，并按 Ctrl+C 关闭旧版。
请保留旧版 data/backups 文件夹，复制到新版相同位置。
编辑内容保存在浏览器同一地址的本机存储内，磁盘备份不包括登录会话或图片/视频本体。
重复启动当前版本会打开已经运行的工作台，不会再启动一份。
其他程序占用端口时会选备用端口；浏览器数据按地址分别保存，旧数据不会自动跟随新端口。

【视频合并】
需要另外准备 FFmpeg 与 ffprobe：https://ffmpeg.org/download.html
可以把两个可执行文件（Windows 为 ffmpeg.exe / ffprobe.exe）放到 tools 文件夹，再启动工作台；也可以安装后加入 PATH。
没有 FFmpeg 时其余工作台功能可用，本地合并不可用。

【真实 AI 与数据】
使用原网站邮箱密码登录，按原站权限和计费调用文本、图片与视频接口。仅 Google 登录且未设密码的账号暂不能直接登录。
当前没有 YouTube 自动同步，使用 CSV 导入数据。
Windows/macOS 真机安装、真实账号生成和浏览器视觉尚未完成验证。此包首次启动需要联网，不是完整离线安装包，也不是 EXE/DMG 安装器。
