# SignalCraft 产品收口验收报告

日期：2026-09-05。范围：本地实现、自动测试与有限浏览器验收。没有提交、推送或部署本轮修改；没有触发视频生成、付费模型或数据库迁移。

## 1. Golden Path

发现方向 → 判断机会 → 确定做法 → 选择测试 → 进入制作。

共享决策工作台已接入雷达、短视频评估和长视频评估。默认减少重复入口，深入分析与旧创作流水线仍可展开。完整真实账号端到端验收尚未完成。

## 2. Trend Radar

- All / Shorts / Long-form：聚合展示，不混用样本池、阈值或评分。
- 四种视图：为你推荐、市场机会、正在爆发、值得探索。
- 默认最多 3 个优先方向和 1 个探索方向；去重、稳定排序，证据不足时不补假卡片。
- 市场事实与个人适配排序分离；数据缺口、来源、置信度继续可查。
- 缺少子赛道或可复用机制时，不将宽泛类目包装成明确可执行机会。

## 3. Creator Profile V1

LIGHT / RULE_BASED。六项可跳过的显式条件：形态、出镜、每周时间、AI 熟练度、预算、目标。按当前账号隔离保存在本机；不宣称已经跨设备同步。

只有带来源的制作要求才能参与相应适配判断；上游未提供时显示未知，不制造精确适配分。资料只影响个人推荐，不改写市场事实。

## 4. 赛道评估

决策优先，进入窗口、推荐做法、证据和测试选择逐步展开。统一判断枚举和独立形态规则已集中管理，阈值标记 CALIBRATION_REQUIRED，不宣称已完成统计校准。雷达上下文携带来源、形态和账号范围；没有唯一匹配时不悄悄改选其他机会。

## 5. 内容机制、原创性与差异化

整合到“推荐做法”，默认 2–3 个改动。衰退/稀释不会包装成增长。来源缺失时原创性为未知；高风险必须显式确认。风险依据当前选中的测试，而非列表第一个候选。规则建议与实际观察有独立来源标签。

## 6. 测试计划和制作入口

- Shorts：最多 10 条、4/3/3 分组上限；当前数据缺口不自动凑满。可以创建带已携带视频来源的用户确认测试假设，保存到现有账号选题入口。
- Long-form：最多 3 条，复用现有 READY Idea；精确锁定测试、问题、承诺、机制与来源。
- 新增保存测试方案分支，复用现有账号隔离存储。按测试隔离幂等键，不混入其他 Idea 的脚本/分镜。
- 创作条件与决策上下文保留为用户/客户端上下文，不写成市场事实。
- 保存只到 RESEARCH_REQUIRED，下一阶段创作仍需显式操作；不调用 LLM 或视频 Provider。
- 前端提交前先检查后端 test-plan-v1/saveOnly 能力；旧后端不支持时阻止 POST，避免旧接口把保存请求解释为模型生成。

## 7. 合并、隐藏和延后

合并：雷达公共操作、个人条件、决策卡、推荐做法和测试选择。

折叠：长视频复杂筛选、解释面板、深度分析与旧生产流水线。旧实现文件保留兼容，不进行无关删除。

延后：新的推荐模型、自动 LLM 逐卡分析、自动补齐十条测试、跨设备 Profile 同步，以及缺少真实证据的制作难度/风险估计。

## 8. 保护范围与代码复核

本轮未修改排行榜、公开发现、频道诊断、Canvas、Shorts 识别、Provider routing 或 GenerationJob 核心。工作树中既有 HF/compute 修改保留原样，不属于本轮新工作。

五轴复核：正确性（锁定选中测试、上下文与格式）；安全性（鉴权、账号隔离、旧部署 fail-closed、无自动生成）；维护性（中央规则/共享组件）；性能（深层面板按展开挂载、无逐卡模型请求）；体验（紧凑层级、空态和未知状态诚实）。没有为凑齐目标而增加假数据或新 GPU Provider。
